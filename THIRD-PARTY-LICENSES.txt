Transcriber's own source code is licensed GPL-2.0-or-later (see LICENSE).

This file lists the third-party components that are BUNDLED INSIDE the
distributed artifacts -- the Windows zip, the Linux AppImage, and the macOS

Corresponding source for the copyleft components, with exact versions and

--------------------------------------------------------------------------------
EFFECTIVE LICENSE OF THE DISTRIBUTED BINARY: GPL-3.0
--------------------------------------------------------------------------------

Transcriber's source is offered as GPL-2.0-OR-LATER.  The distributed binary,
however, bundles components that are more restrictive than that:

  * x264 and x265 are GPL-2.0-or-later ONLY.  Their compiled libraries ship
    inside the sidecar executable.
  * The bundled FFmpeg was built with --enable-version3 (confirmed by reading
    the configure string out of the shipped avutil binary), pulling in
    GMP and opencore-amr under version-3 terms.

Combining GPLv3-terms components with GPL-2.0-OR-LATER source is permitted --
the "or later" clause allows the combined work to be conveyed under GPLv3 --
but the resulting binary CANNOT be offered under GPLv2-only terms.

  => The distributed artifact is conveyed under the GNU General Public
     License, version 3 or later.
  => The project's own source remains GPL-2.0-or-later.

See SOURCE-PROVENANCE.txt for the full configure string, and for a documented
inconsistency in it that a reviewer should be aware of.
