## Direction contract

THESIS: This is a verbatim record, not a chat app — refuses the bubble-and-badge messaging-UI default every transcription tool defaults to.

OWN-WORLD: Paper-white page, near-black ink, one red "LIVE" stamp reserved for active capture. Speaker tags (SYS/MIC) rule the left margin like a stenographer's transcript, not colored chat badges. Monospace for timestamps/tags, a plain serif-free reading face for transcript body text.

STORY: User opens the app, sees a blank ruled page waiting; pressing Start stamps LIVE and text appears line by line in the margin-tagged format as it's spoken; dropping a file instead shows the same page filling in at once with a progress mark.

FIRST VIEWPORT: A transcript page, centered, ruled left margin for speaker tags, large quiet Start control and file-drop target above the fold when idle; settings (device/model/language) tucked in a collapsible strip, never competing with the page itself.
