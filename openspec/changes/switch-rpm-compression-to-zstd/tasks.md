  **Size: no real change, and an earlier claim here was wrong.** This note first recorded "16 MB smaller" (281.8 MB local zstd versus 297.7 MB CI gzip). That comparison was invalid: the CI-built zstd package is 297.2 MB, and `rpm -qpl` shows it holds 27 files against this local build's 21. The six extra files are Hugging Face download bookkeeping under `resources/model/.cache/huggingface/` that the local `src-tauri/resources/model/` didn't have at build time. So zstd's effect on size is ~neutral (297.2 vs 297.7 MB), exactly as proposal.md predicted, and the apparent win was a content difference, not compression. Corrected here rather than deleted, so the mistake stays visible.

  **Separate finding, worth its own change:** those `.cache/huggingface/` files (lock files, `CACHEDIR.TAG`, a trees JSON) are being shipped inside every Tauri bundle, because `tauri.conf.json`'s `bundle.resources` copies `resources/model` wholesale. `build_portable.py` already excludes `.cache` from the CLI archive; the `.deb`, `.rpm` and AppImage do not. Harmless but pointless payload.
